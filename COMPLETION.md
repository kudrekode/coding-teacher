## Incomplete or unverified scope

- **Go (5), Rust (5), Swift (3):** adapters, detection, lessons, starter/reference code and fixtures exist. The compilers are not installed on this machine. Those 13 references and their successful-compilation/error journeys are **unverified**, and their Run/Submit controls are disabled here. No execution has been simulated.
- Projects support one editable implementation file plus optional read-only context, rather than a general multi-file build environment. React testing uses actual React in jsdom; there is no visual component preview or full semantic TSX checker.
- Execution is for **trusted local code**. Deadlines, output caps, temporary directories, a JS heap limit and loopback/origin restrictions exist; OS-level filesystem/network isolation, hard native/Python memory quotas and guaranteed descendant containment do not.
- TypeScript diagnostics currently refer to a combined source-and-fixture compilation unit; fixture errors may refer to lines outside the visible source file.
- Visualisations use explicit guided steps, not arbitrary source tracing. Topic mastery is an exercise-coverage estimate. Additional roadmap topics are future content, not completed lessons. Firefox/WebKit and a formal accessibility audit were not performed.

## Run it

Dependencies are installed in this workspace. Start development with `npm run dev`, then open **http://127.0.0.1:5174**. A fresh installation uses `npm ci` and `python -m pip install -r requirements.txt` first.

For the production build, run `npm run build` then `npm start` and open **http://127.0.0.1:4318**. With that server running, `npm run test:production` reproduces the production browser smoke check. Installation, architecture, safety limits, test commands and extension instructions are in [README.md](README.md).
